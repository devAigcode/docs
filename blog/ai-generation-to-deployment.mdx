## What you'll learn

- **Managed deployment** — deploy directly with AutoCoder.cc for the fastest way to go live
- **Domain options** — use an AutoCoder subdomain, buy a new domain, or connect an existing one
- **Run locally** — export the source code and continue development in your own environment
- **Self-hosted deployment** — deploy to your own server and manage your own database and infrastructure
